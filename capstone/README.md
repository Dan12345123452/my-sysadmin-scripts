# Итоговая защита — системное администрирование

Выбранная дорожка: База.

## Структура

- `evidence/` — свежие результаты проверочных команд.
- `report/` — материалы для подготовки итогового PDF-отчёта.

## Проверка

Доказательства собираются на Ubuntu VM `sysadmin-host`.
Итоговый PDF-отчёт будет загружен в LMS согласно требованиям курса.
