# Мониторинг ресурсов Linux

## Описание
Проект содержит Bash-скрипт для периодического мониторинга системных ресурсов Linux.

## Что отслеживается
- Оперативная память и swap с помощью `free -h`.
- Использование дискового пространства с помощью `df -h /`.
- Время работы и средняя нагрузка с помощью `uptime`.

## Файлы проекта
- `script.sh` — скрипт мониторинга.
- `monitor.log` — журнал с результатами замеров.
- `sample_output.txt` — пример вывода мониторинга.
- `README.md` — документация проекта.

## Запуск
1. Перейдите в каталог проекта.
2. Сделайте скрипт исполняемым: `chmod +x script.sh`
3. Запустите: `./script.sh`
4. Чтобы остановить мониторинг, нажмите `Ctrl+C`.

## Настройки
По умолчанию скрипт записывает результаты в `monitor.log` каждые 10 секунд.

## Журнал мониторинга
Файл `monitor.log` создаётся автоматически при запуске `script.sh`.
Новые замеры добавляются в конец файла каждые 10 секунд.
